1. 快速开始

1.1 安装启动

方式一：EXE 安装包

  1. 下载 AI_Suite_*_x64-setup.exe
  2. 双击安装，选择安装目录
  3. 桌面双击 AI Suite 图标启动

方式二：命令行

pip install fastapi uvicorn pillow psutil python-pptx ezdxf
python gen_web.py &
python model_orchestrator.py &
start http://localhost:5000/chat

1.2 配置 API Keys

创建 ~/.model_keys.json：

{
  "openrouter_key": "sk-or-v1-...",
  "deepseek_key": "sk-...",
  "volcengine_key": "ark-...",
  "google_key": "AQ..."
}

（可选）加密存储：python key_vault.py encrypt

1.3 依赖安装

依赖用途安装

2. 界面说明

2.1 主界面布局

启动后进入 Chat UI，四个标签页切换：

标签快捷键功能
💬 对话Ctrl+1AI 对话，支持本地 Ollama + OpenRouter 云端
🎨 生图Ctrl+2文字描述生成图片（SDXL/Seedream/云端）
🎬 生视频Ctrl+3文字/图片生成视频（Seedance/Wan）
🤖 AgentCtrl+4自主 Agent，自动调用工具完成任务

2.2 对话模式

左上角选择模型来源：本地·免费无限（Ollama）或 云端·多模型（OpenRouter）。

云端模式可选：DeepSeek V4 Pro / Claude Fable 5 / Sonnet 4.6 / Haiku 4.5 / GPT 5.5 / Gemini 等。

💡 提示：按 Ctrl+Enter 发送消息，Ctrl+N 新建会话，Ctrl+V 粘贴图片上传。

2.3 Agent 模式

输入任务描述，Agent 自动拆解并调用工具执行。支持三种执行方式：

按钮说明
执行流式执行，实时展示思考和工具调用过程
后台异步后台执行，完成后 Windows Toast 通知
团队多 Agent 协作：自动分解为并行子任务，4 角色专家协同

2.4 命令面板

按 Ctrl+K 弹出命令面板——搜索工具、切换模式、执行快捷操作。

5. 高级功能

5.1 对话记忆

所有对话自动保存到 ~/.ai-suite/memory.db，左侧边栏显示历史会话。

  • 点击会话切换历史对话
  • 悬停显示删除按钮
  • 首条消息自动作为会话标题

5.2 RAG 记忆系统

Agent 自动记住用户偏好和上下文，越用越聪明。

  • 向量嵌入 + 语义检索
  • Agent 自动注入相关记忆到系统提示
  • API: GET/POST /api/rag/memory

5.3 本地文档索引 (Local RAG)

索引目录下所有文档，语义搜索。

# 索引文档目录
POST /api/rag/index {"path": "~/Documents"}

# 搜索
GET /api/rag/search?q=机器学习教程

5.4 MCP Server

将全部 47 工具暴露为标准 MCP 协议，供 Claude Code / Codex 等外部 AI 客户端调用。

# 启动 MCP SSE Server
python mcp_server.py --sse --port 5100

# Claude Code 配置 (~/.claude.json):
{
  "mcpServers": {
    "ai-suite": {
      "url": "http://127.0.0.1:5100/sse"
    }
  }
}

8. 常见问题

⚠ 打开时有多个弹窗？
确保使用最新版 EXE（v4.1+），已修复控制台窗口和双托盘图标问题。
⚠ Agent 不工作？
检查编排器(5001)是否在运行：python model_orchestrator.py
检查 API key 是否配置：~/.model_keys.json
⚠ 视频工具报错？
确保 ffmpeg 已安装：C:\ffmpeg\bin\ffmpeg.exe
💡 如何让 Agent 更聪明？
多用 RAG 记忆功能——Agent 会自动记住你的偏好。遇到问题时给出明确的任务描述和期望结果。
💡 如何扩展工具？
写一个 Python 插件放在 ~/.ai-suite/plugins/，或连接外部 MCP Server。
